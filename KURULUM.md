# Dernek360 Duyuru Merkezi

Bu klasördeki `index.html` ve `announcements.json` dosyalarını `Dernek360-Releases` deposunun ana dizinine yükleyin.

GitHub deposunda **Settings → Pages → Build and deployment → Deploy from a branch** seçin. Branch olarak `main`, klasör olarak `/(root)` seçip kaydedin. Sayfa birkaç dakika sonra şu adreste açılır:

`https://dernek360-byakbey.github.io/Dernek360-Releases/`

Yönetim panelinden yayın yapabilmek için GitHub **Settings → Developer settings → Personal access tokens → Fine-grained tokens** bölümünde yalnızca `Dernek360-Releases` deposuna ve **Contents: Read and write** iznine sahip bir anahtar oluşturun. Anahtar site kaynaklarına yazılmaz veya tarayıcıda saklanmaz.
